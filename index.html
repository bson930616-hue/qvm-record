連線

怎麼取得金鑰？
  1. 用瀏覽器登入 GitHub，打開 github.com/settings/personal-access-tokens/new
  2. 名稱隨意（例如 QVM App）；有效期限選 1 年
  3. Repository access 選 Only select repositories，只勾你的 QVM 私有儲存庫
  4. Permissions → Repository permissions：Contents 選 Read and write；若想用「立即更新績效」，再把 Actions 選 Read and write
  5. 按 Generate token，複製以 github_pat_ 開頭的那串，貼到上面
金鑰只存在這支手機的瀏覽器裡，不會傳到別處。換手機或過期時，重新產生一組貼上即可。
